# Stack

## Languages

- **JavaScript** — Primary language for frontend and backend work.
- **TypeScript** — Used for type safety in larger projects and when collaborating.
- **Python** — For scripting, data processing, and backend utilities.

## Runtimes & Frameworks

- **Node.js** — Server-side runtime for backend services and tooling.
- **React** — Frontend framework for building component-based UIs.

## Development Tools

- **VSCode** — Primary editor; configured with extensions and keybindings.
- **Claude Code / Cursor** — AI-assisted development; used for onboarding, planning, and implementation.
- **Prettier** — Consistent code formatting across projects.
- **ESLint** — Linting and code quality checks.
- **Husky** — Git hooks for automated pre-commit and pre-push tasks.
- **Jest / Vitest** — Test runners for unit and integration tests.
